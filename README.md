# 2023~2025 대학 성과관리 대시보드

신한대학교 중장기 발전계획 성과관리 대시보드 배포 저장소입니다.

- 2023·2024·2025 연도별 성과 현황
- 종합현황 / 성과분석 / 위험신호 / 부서분석 / 환류관리 / 연도별 추세
- 2025년을 추세관리 기준연도로 사용
- 150% 상한 적용 비교 및 목표값 적정성 진단

웹 배포용 정적 파일은 저장소 루트에서 제공합니다.
