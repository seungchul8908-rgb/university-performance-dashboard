# 2025 대학 성과관리 대시보드

`dist/index.html`을 브라우저로 열거나 정적 웹 서버에서 `dist` 폴더를 제공합니다. 기본 209개 지표가 포함되어 있습니다.

- 엑셀 업로드: 2025 달성값 시트와 원본 헤더 구조가 있는 `.xlsx` 또는 `.xls` 파일, 최대 30MB
- 업로드 파일은 브라우저 메모리에서 분석합니다. 서버 전송이나 영구 저장은 하지 않습니다. 새로고침 시 기본 자료로 돌아옵니다.
- 영역, 담당부서, 핵심지표 구분, 달성여부, 검색 필터
- 영역 및 부서 막대를 클릭하여 필터 적용
- 지표 행을 클릭하거나 Enter 키로 측정방법과 원본 위치 확인
- 현재 필터 결과 CSV 다운로드

## 집계

분석 단위는 세부 측정 행입니다. 병합값은 해당 병합 범위 내에서만 전달합니다. 원본 달성 판정을 보존하며 미판정 항목을 달성 비율의 분모에서 제외합니다. 원본 달성률 100은 100%입니다. 공동부서는 원본 문자열 단위로 집계합니다. 가중치 반영값은 전체 점수로 합산하지 않습니다. 기본 자료는 전체 209개, 달성 166개, 미달성 43개, 핵심지표 120개입니다.

연도 비교 및 업로드 자료 영구 저장은 현재 범위에 포함되지 않습니다.

엑셀 파서: SheetJS Community Edition 0.20.3, 공식 배포 파일(https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js), Apache-2.0.

## 보고서 기준 상한 비교
세부지표 달성률에 150% 상한을 적용한 뒤 실행과제별 가중평균을 계산하고 과제 점수의 단순평균으로 영역 및 전체 평균을 표시합니다. 목표값 0 및 결측은 비교 계산에서 제외하며 원본 판정은 보존합니다. 기본 평균 139.71% → 106.55%, 달성 실행과제 44 → 41개. 80% 미만 28개, 130% 이상 51개를 원값 기준으로 별도 표시합니다. 실행과제 목록으로도 전환 가능합니다. 부분 필터에는 가중치 재정규화와 부분 계산 안내가 표시됩니다. AI 및 통계 진단 기능은 포함하지 않습니다.

상한 선택: 130%와 150%를 전환할 수 있습니다. 기본값은 보고서 기준인 150%입니다. 130%는 비교 시나리오이며 기본 전체 평균 101.81%, 달성 실행과제 40개입니다. 구간별 대상은 원값 기준을 유지합니다.

그래프 표시: 영역별 달성 비율 및 지표 수를 가로·세로 그래프로 전환할 수 있으며, 부서별 미달성 상위 6개 부서도 가로·세로 보기를 제공합니다. 막대 클릭 시 영역 또는 부서 필터를 적용합니다. 작은 화면에서 세로 그래프는 가로 스크롤로 전체 항목을 확인할 수 있습니다.

## 지표 개선 검토 대상
전용 담당부서 필터와 부서별 묶음 표시를 제공합니다. 현재 조회의 80% 미만, 130% 이상 대상 및 조회 조건을 3개 시트의 실제 .xlsx 파일로 다운로드합니다. 원값, 선택 상한, 변화량은 숫자 셀로 저장합니다. 실행과제 기준에서는 원값으로 대상을 선정한 후 관련 담당부서로 조회합니다.
그래프는 세로형만 제공하며 영역별 그래프의 기본 화면은 실행과제 평균 원값과 선택 상한(130/150%) 비교입니다. 지표 달성 비율 및 지표 수 보기에서도 상한으로 원본 판정을 변경하지 않습니다.

## 실행과제(성과지수) 보기
상단 조회 기준을 전환하면 요약 카드, 영역 및 부서 차트, 현황 목록과 CSV를 실행과제 단위로 조회합니다. 원값 가중평균 100% 이상을 달성으로 판정하며 선택 상한 적용 점수도 함께 표시합니다. 담당부서·지표 구분·검색은 관련 지표가 포함된 과제를 선택하고, 점수는 과제 전체 구성 지표로 계산합니다. 과제 행을 선택하면 구성 지표와 가중치를 확인할 수 있습니다. 여러 부서가 참여한 과제는 부서 차트에서 각 부서에 1개씩 집계하므로 부서별 수의 합은 전체 과제 수와 다를 수 있습니다.

## 전략과제 보기
조회 기준에서 전략과제를 선택합니다. 실행과제 번호의 상위 코드(S1, M1 등)로 묶고 소속 실행과제 점수의 단순평균을 계산합니다. 산출 불가 실행과제는 평균에서 제외합니다. 원값 평균 100% 이상을 달성으로 판정합니다. 상한은 세부지표에 적용한 뒤 실행과제 가중평균, 전략과제 단순평균 순으로 계산합니다. 기본 자료에 전략과제명이 없어 상위 코드로 표시하며, 업로드 자료에 전략과제 또는 전략과제명 열이 있으면 해당 명칭을 사용합니다. 요약·차트·상세·CSV 및 개선 검토 대상 조회를 지원합니다. 부서 필터에서도 전략과제 전체 구성 과제로 점수를 계산합니다.

## 다른 컴퓨터에서 이어서 수정하기

```sh
git clone https://github.com/seungchul8908-rgb/university-performance-dashboard.git
cd university-performance-dashboard/performance-dashboard
```

`dist/index.html`을 브라우저로 열어 확인하고 `dist` 안의 HTML/CSS/JavaScript를 수정합니다. 별도 설치나 빌드가 필요하지 않습니다. 엑셀 처리 라이브러리 `xlsx.full.min.js`와 기본 데이터 `default-data.js`도 포함되어 있습니다.

작업 시작 전 저장소 루트에서 `git pull`로 최신 소스를 받고, 작업 후 아래 명령으로 저장합니다.

```sh
git add performance-dashboard
git commit -m "Update performance dashboard"
git push
```

소스 다운로드 ZIP을 다시 만들려면 `performance-dashboard` 폴더에서 `python build-source-download.py`를 실행합니다. 원본 엑셀, 개인 환경 설정, 테스트 캡처 및 임시 실행 파일은 저장소에 포함하지 않습니다.
